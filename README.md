# 経費予測Pilot Streamlit MVP v1.8

## v1.8 update
- 見積書に記載された「値引」「値引き」「端数値引き」「値引き調整」「割引」を抽出対象に追加。
- 表紙・工事内訳サマリーにだけ存在する値引も、Excel明細へ「値引・割引」としてマイナス金額で反映。
- 既に明細Parserが取得している値引行は重複追加しない。
- 一括変換サマリー／画面の変換結果に「値引・割引」列を追加。
- 原本にない値引額は生成しない。
- v1.7のBAN複数ページ自動検出、HIMI/SANTEN、0円明細、税額原本優先ロジックは継続。
